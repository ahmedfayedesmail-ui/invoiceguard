How you can check this yourself

After this page loads, the server has no part in the analysis. It sends the page with a rule (Content-Security-Policy: connect-src 'none') that makes your browser refuse any network call from it. Open your browser's developer tools, Network tab, load a file, and nothing new appears. The counter above reads your browser's own request log.

What this page does not do. It does not check the buyer VAT number with the EU VIES service: the EU service does not accept calls from web pages, so that check needs a server and is switched off here. It does not see your seller invoices, so it cannot tell whether you already issued an invoice. It checks the file's own data (format, Spanish NIF control character, required fields). The PDFs it makes are samples with a made-up seller and the number SAMPLE-0001. They are for looking at the layout only.
What we count. Only these four numbers, as plain tallies: a page was opened; a check was started; a check finished, with a size band for the amount found (0, 1-29, 30-49, 50-199 or 200+ EUR) and a coarse result (all ready, some held, none ready, unreadable); a checkout button was clicked. We never receive your report, its rows, file names, order numbers, buyer details or exact amounts. There is no cookie, no stored ID and no tracking across visits. Counting is switched off in this build. Anything beyond these tallies would need your explicit consent here first.
