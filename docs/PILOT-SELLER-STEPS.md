# Pilot seller steps: send us only the header line

Goal: we need to see the exact column names of your real Seller Central order report. We do not need any customer data. Send ONLY the first line (the header row). Never send order rows, names, addresses, VAT numbers or emails.

Who can help: any seller who is willing. It must be the seller's own account. Never use a workplace or an employer's account.

## English

1. Sign in to your own Seller Central account.
2. Open Reports, then Order Reports (the menu name can differ a little by country).
3. Find "Add or remove order report columns". Switch on "Buyer tax identifiers" and "Buyer company name". Save.
4. Request a report for a short date range and download it as a tab-delimited text file.
5. Open the file in a plain text editor (Notepad, TextEdit). Do NOT open it in Excel.
6. Copy ONLY line 1 (the header row) and send it to us. Delete everything else.
7. If you also see a "VAT Invoice Data Report" (or similar) in Reports, do the same: send only its first line.
8. Optional: tell us the name of each menu you used, so we can fix our guide.

## الخطوات بالعربي (مبسطة)

الهدف: عايزين نشوف أسماء الأعمدة الحقيقية بس. مش محتاجين أي بيانات عملاء.

1. ادخل على حساب Seller Central بتاعك أنت (حساب بتاعك أنت شخصيا، مش حساب شغل ولا شركة حد).
2. من القائمة افتح Reports ثم Order Reports (الاسم ممكن يختلف شوية حسب البلد).
3. دوّر على "Add or remove order report columns" وفعّل "Buyer tax identifiers" و "Buyer company name" وبعدين Save.
4. اطلب تقرير لفترة قصيرة ونزّله كملف نصي (tab-delimited text).
5. افتحه بأي محرر نصوص بسيط (Notepad أو TextEdit). متفتحوش في Excel.
6. انسخ السطر الأول بس (سطر العناوين) وابعتهولنا. امسح كل الباقي.
7. لو لقيت تقرير اسمه "VAT Invoice Data Report" أو شبهه، اعمل نفس الحاجة: ابعت سطره الأول بس.
8. اختياري: قولنا أسماء القوائم اللي دخلت عليها عشان نصحح الدليل.

مهم: ممنوع تبعت أي صف فيه بيانات عملاء (اسم، عنوان، رقم ضريبي، إيميل).
